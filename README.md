# weGov
An open source governance platform for the whole world.

weGov is digital, open source and decentralised infrastructure that lets communities govern themselves. It is built so that every person, including the world's poorest, has an equal voice.

**Start here: [The weGov Manifesto](MANIFESTO.md).** It sets out the principles the platform is built on and the design commitments that follow from them.

## Status

Early stage. The manifesto is being drafted, and the platform design comes next.

## Contributing

Every part of this project is open to discussion, the manifesto included. Open an issue or a pull request to propose a change.
