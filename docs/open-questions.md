# Open Questions

**Question everything here.** weGov is meant to be governed by everyone, and that includes its own foundations. This register tracks the questions we have not answered, the assumptions we are unsure of, and the challenges people raise against the structure itself.

If you think something in the [Manifesto](../MANIFESTO.md) or the [design documents](layers.md) is wrong, unfair, unworkable or missing, that is a contribution. [Here is how to raise it](../CONTRIBUTING.md#1-question-the-structure).

---

## How this register works

- Each question has an ID (for example `L-03`) so it can be referred to anywhere.
- **Status** is one of:
  - **Open:** no answer yet.
  - **Discussing:** there are proposals on the table.
  - **Proposed answer:** a draft answer is waiting for agreement.
  - **Settled:** answered for now, with a link to the decision. A settled question can always be reopened.
- New questions come in through [GitHub issues](../CONTRIBUTING.md#1-question-the-structure) and are added here once they are recognised.
